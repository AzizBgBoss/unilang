# Flag 6 visual demo

An animated 128x64 RGB332 night scene with a flowing neon aurora, twinkling
stars, a glowing ringed planet, layered parallax mountains, and a passing
comet. Press Enter to exit.

Compile from the repository root:

Compile from the repository root:

```powershell
python .\compiler.py .\examples\flag6\flag6.c -o .\examples\flag6\flag6.ulc
```

Run it with the SDL C interpreter:

```powershell
.\C-interpreter\main.exe .\examples\flag6\flag6.ulc
```
